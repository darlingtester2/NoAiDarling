Question 1: Are there any parts of the project where any AI use at all is unacceptable?
Answer: in the source code and code and art

Question 2: Are there any parts of the project where all AI use is acceptable?
Answer: AI code and AI assisted code will not be accepted anywhere. AI will not be accepted in code and source code. AI art will not be accepted because most of the time it looks bad. AI vulnerability scanners are allowed only by the people in the project leadership. If AI is used you must specify the AI type and AI model. The model used must be an "open data" model. Chinese AI models are not allowed and banned. Anything by AI must be reviewed and analyzed. You must make sure your AI model does not violate patents and copyright and is not trained on anything that does. The model cant be trained on like apple things that you are not allowed to use (like closed-source frameworks).

Any types of AI and AI tools not mentioned here will by default be not allowed.

Question 3: how is the ai policy enforced?
Answer: it is enforced by the project leadership and by contributors that want to and people that want to become reviewers
